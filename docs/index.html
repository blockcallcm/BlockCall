04 · LigeroLight

Hecha para
no notarse.Built to
go unnoticed.

Usa la API oficial de Android para filtrar llamadas: el sistema la despierta solo cuando entra una llamada, decide en milisegundos y la vuelve a dormir. Ningún limpiador de tareas puede detenerla, y si algo fallara, la llamada entra: nunca pierdes a un contacto.It uses Android's official call screening API: the system wakes it only when a call arrives, it decides in milliseconds and goes back to sleep. Task killers can't stop it, and if anything failed the call would ring: you never miss a contact.

Sin permiso de internet, sin anuncios, sin rastreadores. Tus contactos y tu historial nunca salen del teléfono.No internet permission, no ads, no trackers. Your contacts and history never leave your phone.
